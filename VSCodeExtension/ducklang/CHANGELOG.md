# Change Log

All notable changes to the "ducklang" extension will be documented in this file.

## 0.1.0

- Registered the `duck` language for `.dk` files and fixed the language id that
  kept the grammar and snippets from applying.
- Added syntax highlighting for the language as implemented by the bootstrap compiler.
- Added comment, bracket, auto-closing, and indentation support.
- Added snippets for Duck source and project files.
- Added the `duck-project` language for `.dkp` files.
- Added the `$duck` problem matcher for compiler errors and failed test assertions.
